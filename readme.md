# Автотест Фреймворк

Данный фреймворк предназначен для автоматизированного тестирования различных видов приложений (Web, Desktop, Backend)
использующий как BDD сценарии (Cucumber) так и pure Java (н-р, Junit5)

### Версии

Актуальная версия 3.3

Все версии фреймфорка и их описание можно найти
по [ссылке](https://gitlab-01/automated-testing-technology/core-frameworks/fr-chicory-framework/-/releases)

# Технологии

- HTTP (REST, SOAP)
- Wiremock (создание заглушек и валидация полученных запросов)
- SQL, PL/SQL
- FTP
- RabbitMQ
- Selenium/Selenide
- FlaNium (Winium)
- AutoIT
- SikuliXApi
