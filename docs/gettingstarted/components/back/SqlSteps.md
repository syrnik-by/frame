## SQL шаги

### Виды SQL запросов

В фреймворке существуют 2 вида SQL запросов:

```gherkin
И отправить в БД методом SELECT SQL запрос:
И отправить в БД методом EXECUTE SQL запрос:
```   

_**SELECT**_ - Выполняет Select запрос, который должен в ответ вернуть таблицу, например: `select * from table`. Возвращаемая таблица может быть потом
провалидирована. Предварительно в рамках одного sql-скрипта при необходимости можно выполнить Update или Процедуру

_**EXECUTE**_ - Выполняет любой SQL или PL/SQL скрипт. Pl/SQL скрипт может возвращать логи методом `dbms_output.put_line()`. Далее эти логи могут быть
провалидированы

### Валидация SQL ответа

#### **Валидация таблицы.**
Для валидации содержимого возвращенной таблицы используется следующий шаг:

```gherkin
И ответ содержит записи:
| classified         | msg_id                                       | type     |
| 23                 | bed6fe287e244f50a766cdfd4cb757e4             | CheckReq |
| bigdecimal::<=::23 | string::==::bed6fe287e244f50a766cdfd4cb757e4 | CheckReq |
```

В первом ряду указываются имена полей, в проверке участвуют только те поля, которые были указаны.

В следующих рядах указываются записи со значениями, которые должны содержаться в возвращенной таблице. Значения могут быть указаны:

- в простой форме (как это сделано в 1 записи), в таком случае они будут приведены к типу `String` и сравнены методом `eqauls`
- в форме выражения `тип_значения::оператор_сравнения::значение`, в таком случае, значение будет приведено к этому типу и сравнено указанным
  оператором.

Подробнее о [операторах](../../core/Matchers.md)

#### Валидация логов. 

Для валидации логов, полученных при выполнении скрипта методом `EXECUTE` используется следующий шаг:

```gherkin
#language:ru
И SQL ответ содержит в логах строки:
| 2535173987 |
```

### Подключение к СУБД системы

В фреймворке существуют 2 способа подключения:

```gherkin
И установить подключение к БД:

И создать коннектор c {word} к БД:
| url                                                 | user         | password         | dbms     |
| jdbc:postgresql://${{db.host}}:5432/{database_name} | ${{db.user}} | ${{db.password}} | POSTGRES |
```

где _{database_name}_ - наименование каталога / схемы / ДБ (указывать по необходимости).

Более подробно про формат JDBC URL для различных СУБД в [статье](https://www.baeldung.com/java-jdbc-url-format).

Коннектор рекомендуется использовать, когда в рамках одного теста необходимо подключаться к нескольким БД (В рамках одной СУБД, н-р PostgreSQL) / СУБД,
