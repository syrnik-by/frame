# Модуль AutoIt-elements

Модуль AutoIt-elements содержит в себе элементы и необходимый функционал для автоматизации тестирования windows приложений.

### Cостав модуля:

- configuration - работа с доступными проперти и конфигами
- elements - реализованные элементы
- services - вспомогательные классы
- stepdefs - реализация уникальных относительно других модулей шагов

### Подключение модуля

- Добавляем зависимость:
```
implementation "ru.autotestframework.components:autoit-elements:${core_version}"
```
- Кладем файл jacob.dll по пути JAVA_HOME/bin
- Регистрируем файл AutoItX3_x64.dll в реестре (необходимы права администратора)
```
regsvr32 путь к файлу/AutoItX3_x64.dll
```

### Заполнение проперти:

```properties
framework.ui.driver.autoit.properties - путь до проперти-файла с настройками драйвера
framework.ui.driver.autoit.app.close - принудительное закрытие приложение по окончании каждого теста (по умолчанию - true)
```

### Проперти файл с настройками драйвера:

```properties
app - путь к приложению
```

### Особенности модуля

- Шаг 'ввести с клавиатуры {string}' работает по правилам AutoItScript.

Отправляет имитацию нажатия клавиш в активное окно.

### Параметры

String - Последовательность символов(ключей, клавиш) для отправки.

### Примечания

* AutoIt может отправлять все символы ASCII и расширенный ASCII (0–255). Для отправки символов UNICODE вы должны
  использовать опцию «ASC» и код символа, который вы хотите отправить (см. {ASC} внизу таблицы ниже).

* Синтаксис команды Send () аналогичен синтаксису ScriptIt и команды SendKeys Visual Basic. Символы передаются в том
  виде, в каком они написаны, за исключением следующих символов:

    * '!' - Это указывает AutoIt отправить нажатие клавиши ALT, поэтому команда Send(«Это текст!a») отправит клавиши
      «Это текст», а затем нажмет «ALT+a».
    * '+' - Это указывает AutoIt отправить нажатие клавиши SHIFT; следовательно, команда Send(«Hell+o») отправит текст
      «HellO». Send("!+a") отправит "ALT+SHIFT+a".

      *Некоторые программы очень требовательны к заглавным буквам, т.е. "!A" отличается от "!a". В первом случае
      ALT+SHIFT+A, а второй — ALT+a. Если сомневаетесь, используйте строчные буквы!*

    * '^' - Это указывает AutoIt отправить нажатие клавиши CONTROL; следовательно, команда Send("^!a") отправит "
      CTRL+ALT+a".
    * '#' - отправляет нажатие клавиши Windows; следовательно, команда Send(«#r») отправит команду Win+r, которая
      запускает диалоговое окно «Выполнить()».
* Windows не позволяет моделировать комбинацию «CTRL-ALT-DEL»!
