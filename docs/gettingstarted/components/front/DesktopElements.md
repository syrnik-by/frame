# Модуль Desktop-elements
Модуль Desktop-elements содержит в себе элементы и необходимый функционал для автоматизации тестирования desktop-приложений.
### Cостав модуля:
- actions - манипуляции с мышью и касаниями
- configuration - работа с доступными проперти и конфигами
- elements - реализованные элементы
- enums - вспомогательные константы
- stepdefs - реализация уникальных относительно других модулей шагов

### PageElements
Для правильного взаимодействия с PageObject необходимо у всех элементов создавать конструктор
CustomElement(WebElement element, String title) // На Page не должно быть элементов без наименования, для иниициализации через framework

### Заполнение проперти:

```properties
framework.ui.driver.desktop.path - путь до десктопного драйвера
framework.ui.driver.desktop.properties.path - путь до проперти-файла с настройками драйвера
framework.ui.driver.desktop.app.close - принудительное закрытие приложение по окончании каждого теста (по умолчанию - true)
```
### Проперти файл с настройками драйвера:

```properties
app - путь до тестируемого приложения
debugConnectToRunningApp - возможность подключаться к уже ранее открытому приложению
launchDelay - задержка после запуска приложения
remoteRun - запуск драйвера на удаленном хосте
browserName - имя драйвера
driver_url - урл, где запущен драйвер
```
В данный момент для используется FlaNium Driver представляющий из себя драйвер взаимодействия с тестируемым приложением посредством Windows Automation API и использующий протокол взаимодействия  Selenium REST API.  

Для корректного определения xpath элементов рекомендуется использовать FlaUInspect
