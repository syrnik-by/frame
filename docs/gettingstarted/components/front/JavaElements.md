# Модуль Java-elements

Модуль Java-elements содержит в себе элементы и необходимый функционал для автоматизации тестирования java-приложений.

### Cостав модуля:

- configuration - работа с доступными проперти и конфигами
- elements - реализованные элементы
- services - вспомогательные классы
- stepdefs - реализация уникальных относительно других модулей шагов

### Заполнение проперти:

```properties
framework.ui.driver.java.path - путь до десктопного драйвера
framework.ui.driver.java.properties.path - путь до проперти-файла с настройками драйвера
```

### Проперти файл с настройками драйвера:

```properties
launchMode - тип тестируемого приложения. На данный момент поддерживается два типа: jnlp и jar
jnlp - URL для запуска jnlp
jar - путь до исполняемого jar файла
javaHome - Путь до jre если требуется использовать определенную версию для запуска
startWindowTitle - Наименование стартового окна
```

В данный момент используется Marathon Java Driver представляющий из себя драйвер взаимодействия с тестируемым
приложением,  
использующий Selenium/WebDriver для автоматизации приложений Java/Swing ™ и Java/FX ™.
