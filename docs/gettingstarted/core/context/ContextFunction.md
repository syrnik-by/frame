# Функции контекста

Для генерации данных используются функции контекста, которые обозначаются следующим образом:

`${{functionName:arg}}`, где:
- `functionName` - имя функции
- `arg` - аргументы необходимой функции (передаются одним строковым параметром, который  при необходимости можно распарсить на несколько)

Функции контекста являются частью функционала единого контекста, их можно использовать в любых строковых параметрах в feature файлах, либо в
текстовых файлах.

## Существующие функции (происходит резолв шаблонных значений)
- `${{regex:\d\d}}` - генерирует данные по заданному паттерну
- `${{date:yyyy-MM-dd}}` - возвращает текущую дату в заданном формате
- `${{quarterAt:9999-01-01}}` - возвращает квартал для даты 9999-01-01 в числовом значении (1,2,3,4)
- `${{quarterNow:y}}` - возвращает текущий квартал в числовом значении (1,2,3,4)
- `${{shiftNow:P7D&dd.MM.YYYY}}` - возвращает дату со сдвигом (https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/time/Period.html) от текущей в заданном формате, см 
- `${{timestampNow:y}}` - возвращает текущую временную отметку
- `${{dateConverter:${{periodStart}}&yyyy-MM-dd&dd.MM.yyyy}}` - переводит переданную дату из одного формата в другой
- `${{calc:(5+12)/2&%.1f}}` - выполняет арифметическую операцию и возвращает ответ в указанном формате.
- `${{randomLong:9}}` - генерирует long в диапазоне от 0 - 9
- `${{base64Encoder:текст}}` - кодирует base64
- `${{base64Decoder:SGVsbG9Xb3JsZCE=}}` - декодирует base64
- `${{env:USER}}` - возвращает перемененную из окружения
- `${{file:data/test.json}}` - возвращает содержимое текстового файла с кодировкой по умолчанию
- `${{fileRead:data/test.json&UTF-8}}` - возвращает содержимое текстового файла c указанной после & кодировкой
- `${{fileResolve:data/test.json&UTF-8}}` - копирует файл с подстановкой шаблонных значений, и возвращает путь нового файла c указанной после & кодировкой
- `${{escape:"ООО Рога и Копыта"}}` - возвращает строку с экранированными кавычками \\"ООО Рога и Копыта\\"
- `${{fakerRu:key}}` - возращает сгенерированную строку по `{key}`,
  соответствующую документации из [DataFaker](https://www.datafaker.net/documentation/providers/#provider-groups), [2](https://www.datafaker.net/documentation/expressions), и расширенную
  дополнительными ключами*. 

Пример `key` из документации Faker - `#{Address.streetName}` -> ${{fakerRu:Address.streetName}}

*Дополнительные ключи : 
- `kpp` - КПП
- `innfl` - ИНН физического лица
- `innul` - ИНН юридического лица
- `ogrn` - ОГРН
- `ogrnip` - ОГРНИП
- `snils` - СНИЛС
- `oktmo` - ОКТМО

Для создания собственных функций контекста используйте [инструкцию](ContextCustomFunction.md)
