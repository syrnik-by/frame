# Исключения

Во фреймворке реализован набор исключения для использования внутри фреймворка и подключенных проектах.

### Типы исключений и описания:

- _**AutotestException**_ - Родительское исключение которое выбрасывается при любых проблемах в утилитных классах Core
  фреймворка. Может использоваться в случаях оборачивания каких либо трудноклассифицируемых исключений
- _**ConfigurationException**_ - Исключение которое выбрасывается при любых проблемах при конфигурации/сборке проекта
- _**TimeoutException**_ - Исключение которое выбрасывается по истечении времени ожидания
- _**InitializationException**_ - Исключение которое выбрасывается при любых проблемах при инициализации страниц,
  элементов и т.д.
- _**ExecutionException**_ - Исключение которое выбрасывается при любых проблемах при взаимодействии с Backend
- _**ElementInteractionException**_ - Исключение которое выбрасывается при любых проблемах при взаимодействии с
  елементами UI
