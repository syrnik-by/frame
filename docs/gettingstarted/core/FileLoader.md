### FileLoader

Функционал 
+ Создание нового файла (InputStream)
+ Создание нового текстового файла (InputStream | String)
+ Получение файла
+ Чтение файла (с процессингом контекстных переменных и функций)
+ очистка временных файлов из соответствующей папки

Использование в .feature-файле [только чтение на данный момент]
Через контекстную функцию
* `${{file:data/test.json}}` - возвращает содержимое текстового файла из папки ресурсов (build/re
* `${{file:file:temp/http/test.txt}}` - возвращает содержимое текстового файла из папки
+ от корня проекта (см. выше)
+ по абсолютному пути в Файловой системе, пример: file: C:\git\temp.txt file:file:temp/http/test.txt}. [подробнее](https://springframework.guru/working-with-resources-in-spring)

Пример:

```gherkin
#language:ru
И установлены переменные:
| text | ${{file:data/test.json}} | 
```
