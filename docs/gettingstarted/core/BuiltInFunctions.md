# Основной функционал

### Исполнение цепочки шагов с N количеством попыток

Иногда некоторые шаги проходят не сразу из-за задержек тестируемой системы. В таком случае такие шаги, можно попробовать
выполнить несколько раз. Для этого может быть использована следующая конструкция:

```gherkin
* начало цепочки шагов с 5 попытками с интервалом 1000 мс
... цепочка шагов любой длины
* конец цепочки шагов
```

---

### Временные файлы

Все файлы загружаемые во время сценария могут складываться в папки:

- `temp/ftp` - файлы загруженные ftp шагами
- `temp/http` - файлы загруженные http шагами
- `temp/ui` - файлы загруженные UI шагами

Папка `temp' удаляется после *каждого сценария* и после прогона автотестов  
кроме следующих случаев

1. когда включено сохранение контекста (@SaveContext). В таком случае файлы будут удалены только после завершения автотестов
2. установлена проперти `framework.temp.files.cleaning.enabled:false` - в этом случае файлы не удаляются
