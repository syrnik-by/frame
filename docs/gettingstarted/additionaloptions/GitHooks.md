## Git hooks

Git hooks предназначены для выполнения произвольного кода перед и после коммита, пулла, пуша. В фреймворке автотестирования хуки используются для проверки правильности именований ветки и коммита, а также проверки компиляции проекта.
[Подробнее о хуках](https://www.atlassian.com/git/tutorials/git-hooks)
Если ранее выполнялась команда по настройке гит-хуков (git config core.hooksPath), то необходимо отменить эту настройку:

```
git config --unset core.hooksPath
```
При включенной настройке код хуков копируется из ядра фреймворка в директорию .git/hooks проекта автоматически каждый раз при Сборке проекта локально. Это позволяет централизованно задавать все нужные проверки без необходимости их ручного переноса во все проекты.
Для отключения/включения хуков, нужно в вашем framework.properties добавить настройку(true - отключено по умолчанию)

```
framework.remove.git.hooks=true
```

Если по какой-то причине не устраивают хуки из ядра, например, в хуках ядре запуск проверки на сборку проекта осуществляется посредством Gradle, то при использовании на проекте Maven - хуки из ядра будут неуместны.

Хуки можно переопределить на свои.
Для этого нужно в директории resources (в main или test) создать директорию git-hooks и разместить в ней свои файлы [хуков](https://www.atlassian.com/git/tutorials/git-hooks).

`src/test/resources/git-hooks` 
или
`src/main/resources/git-hooks`
